### Skills to Know About
- /effort — switches between Sonnet (normal) and Opus (max). The team uses `/effort max` for design and architecture sessions, then `/effort normal` to implement. Heavy usage (33x/month) means this is a core part of the workflow — switch to Opus before any session that involves settling a new design decision.
- /model — inspects or changes the active model mid-session. Used when a session shifts character (e.g. from implementation to design review).
- /wrap-up — end-of-session housekeeping: updates CLAUDE.md, saves memories, appends to the recent accomplishments log in ROADMAP.md. Run this before closing any significant session.
- /rename — renames the current session for clarity in the session list. Use it early so you can find sessions later.
- /compact — compresses prior conversation context when the window gets large. Use it when the session has been running long and you notice response quality drifting.
